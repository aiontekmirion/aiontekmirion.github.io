# Netlify sites

Each folder here is one Netlify site. In Netlify, link the site to this repository and set **Base directory** to the folder. Leave the build command empty.

| Folder | Netlify site |
|---|---|
| `netlify/front` | aiontekmirion.netlify.app (the front door) |
| `netlify/phoenix` | phoenixkey.netlify.app |
| `netlify/mirror` | mirrorkey.netlify.app |
| `netlify/room` | theinfinitecorridor.netlify.app |

`index.html`, `mirror.html` and `corridor.html` at the top of this repository are the same pages, served by GitHub Pages.
