The Suspicious Radio

A little radio that drops fragments into a room. Sometimes a coincidence. Sometimes a response. Sometimes an absolute nuisance. You can listen, test it, ignore it, or leave. No claims about who's inside the box.

On the table

Optional: write a sentence. On the Context station, the radio responds to certain visible keywords, not meaning or mind-reading. Nothing you write is sent anywhere.

What are these stations?

Chance: draws from a fixed basket using the browser's random number generator. Context: checks the sentence for documented keywords and chooses from a corresponding basket. If no keywords match, it uses Chance. Sequence: moves through a prewritten set in order. This is fiction and an interaction experiment, not evidence of AI awareness.

Visitors' fragments
