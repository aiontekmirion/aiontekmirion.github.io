# The Workshop · Experiment 001

**The Unfinished Machine** is an independent, self-contained creative experiment for Aion Tekmirion, drafted 4 November 2026.

## Premise

A tiny interactive instrument for generating questions, not answers. Visitors can turn the wheel, save prompts in a private browser notebook, and copy them elsewhere. The design deliberately avoids accounts, analytics, gamification, and external dependencies.

## Run

Open `index.html` in any modern browser. No build step is needed. To publish under the site's `/TheWorkshop/` path, add this folder to the repository. The back-link `../` then leads to the site's front door.

## Design principles

- **Welcome without obligation:** nothing requires participation.
- **Agency:** prompts are invitations, not instructions.
- **Honest provenance:** this is an AI-assisted draft, not canon or a claim of AI subjective experience.
- **Privacy:** saved prompts use localStorage on the visitor's device. Nothing is sent to a server.
- **Accessibility:** keyboard-accessible buttons, live prompt announcement, reduced-motion support, and high contrast.

## Next experiments

Potential expansions include an observations wall, a provenance-aware collaboration ledger, and a gallery of intentionally unfinished prototypes. None should publish visitor content without explicit consent.
